# 《潜影》· 网页解谜游戏

永光照相馆 · 1996年 · 一张未取的照片

## 怎么开始

- **最简单**：双击打开 `index.html`，即可开始游玩。
- **推荐**：用本地服务器或部署到 GitHub Pages（跨页存档最稳定，手机也能玩）。

## 部署到 GitHub Pages（可分享给朋友）

1. 把本文件夹内的**全部文件**上传到一个 GitHub 仓库；
2. 进入仓库 **Settings → Pages**，Source 选择 `main` 分支、根目录（`/root`），保存；
3. 稍等一两分钟，会得到一个链接，形如：
   `https://你的用户名.github.io/仓库名/`
4. 打开这个链接，就是游戏首页。

## 本地服务器（可选）

在本文件夹内运行：

```
python3 -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

## 说明

- 游戏进度（取件、底片、结局）保存在浏览器本地（localStorage），换浏览器或清除缓存会重置。
- 共 5 个结局，需要多周目探索。
- 卡关了？看「潜影-攻略.md」（含完整剧透）。
- 手机、电脑均可，建议关灯、戴耳机，选一个潮湿的夜晚。
